# Politique de confidentialité — Flash Deals

**Dernière mise à jour : 11 octobre 2026**

## 1. Introduction

Bienvenue sur Flash Deals. La présente politique de confidentialité décrit comment EB SARL (ci-après « nous ») collecte, utilise et protège vos informations personnelles lorsque vous utilisez notre application mobile Flash Deals (ci-après « l'Application »).

En utilisant l'Application, vous acceptez les pratiques décrites dans cette politique.

## 2. Informations que nous collectons

### 2.1 Informations que vous nous fournissez
- **Informations de compte** : nom, adresse email, numéro de téléphone
- **Informations de livraison** : adresses de livraison, coordonnées GPS
- **Informations de paiement** : les transactions sont traitées par des prestataires de paiement tiers (Orange Money, MTN MoMo, Moov Money, cartes bancaires). Nous ne stockons pas vos informations de carte bancaire.

### 2.2 Informations collectées automatiquement
- **Données d'utilisation** : pages visitées, produits consultés, historique de commandes
- **Données de l'appareil** : modèle, système d'exploitation, identifiants uniques
- **Données de localisation** : position GPS (avec votre consentement)

## 3. Comment nous utilisons vos informations

Nous utilisons vos informations pour :
- Créer et gérer votre compte
- Traiter vos commandes et assurer la livraison
- Vous envoyer des notifications (offres, commandes)
- Améliorer nos services
- Assurer le support client
- Respecter nos obligations légales

## 4. Partage de vos informations

Nous partageons vos informations avec :
- **OneSignal** : pour les notifications push
- **Google Firebase** : pour le stockage sécurisé des données
- **Transporteurs et livreurs** : pour la livraison de vos commandes
- **Prestataires de paiement** : pour le traitement des transactions
- **Autorités légales** : si requis par la loi

Nous ne vendons jamais vos données personnelles à des tiers.

## 5. Sécurité des données

Nous mettons en œuvre des mesures de sécurité appropriées :
- Chiffrement HTTPS pour toutes les communications
- Stockage sécurisé sur les serveurs Firebase
- Accès limité aux données personnelles
- Authentification sécurisée

## 6. Conservation des données

Nous conservons vos données personnelles aussi longtemps que nécessaire pour :
- Fournir nos services
- Respecter nos obligations légales
- Résoudre les litiges

Vous pouvez demander la suppression de votre compte et de vos données à tout moment.

## 7. Vos droits

Vous avez le droit de :
- Accéder à vos données personnelles
- Corriger vos données
- Demander la suppression de votre compte
- Vous opposer au traitement de vos données
- Retirer votre consentement

Pour exercer ces droits, contactez-nous à : **admin@flashdeals.ci**

## 8. Suppression de compte

Pour supprimer votre compte Flash Deals :
1. Ouvrez l'Application
2. Allez dans **Mon profil** → **Paramètres**
3. Cliquez sur **Supprimer mon compte**
4. OU envoyez un email à **admin@flashdeals.ci** avec l'objet « Suppression de compte »

Vos données seront supprimées dans un délai de 30 jours.

## 9. Données des mineurs

Notre Application n'est pas destinée aux personnes de moins de 18 ans. Nous ne collectons pas sciemment de données concernant des mineurs.

## 10. Modifications de cette politique

Nous pouvons mettre à jour cette politique. En cas de changement important, nous vous informerons via l'Application ou par email.
